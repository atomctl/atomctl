# Hachem

I build AI agents, automation workflows, and tools for coding agents.

[Lie Eater](https://github.com/hachemiskira/lie-eater-claude-code) is a Claude Code mod that checks the proof when a coding AI says "done". It freezes the existing test files, compares them when the AI finishes, and reports `checked`, `don't trust "done"` or `not checked`.

## Selected work

- **[Lie Eater](https://github.com/hachemiskira/lie-eater-claude-code)**: built test-first, and reviewed in three rounds by two other AI models. Its README states what was measured and what was not.
- **Voice and chat agents for small businesses**: outbound and inbound calls, WhatsApp assistants, connected to the shop and the stock system. Client work, private.
- **A client dashboard** in TypeScript (Next.js, Supabase), so that the client runs the agents without me. Private.
